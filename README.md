# Flash-sale-ticketing-platform


## Goals
Learn and showcase skills for system design and data structures and algorithms.  

To build a flash sale ticketing platform using:  
- GitHub actions for a CI/CD pipeline running tests and building a Docker image.
- Terraform, Kubernetes, Argo CD for deployment.
- Prometheus and Grafana for monitoring.
- Redis for cacheing.
- RabbitMQ for message queuing.
